Python Syllabus

Core Python

  • Basics: Interpreter, variables, data types, operators, and loops.
  • Data Structures: Lists, Tuples, Sets, and Dictionaries.
  • Functions: Arguments, lambda functions, scopes, and built-in utilities.
  • OOPs: Classes, objects, inheritance, polymorphism, and dunder methods.
  • Files & Errors: Exception handling and File I/O operations.
  • Advanced Core: Iterators, generators, decorators, and list comprehensions.

Advanced & Web Python

  • Database: SQLite/PostgreSQL connection and SQLAlchemy ORM.
  • Web Frameworks: Flask or Django for MVC web applications.
  • Data & APIs: JSON processing, Requests library, and RESTful APIs.
