Java Syllabus

Core Java

  • Basics: JVM architecture, variables, data types, and loops.
  • OOPs: Inheritance, polymorphism, encapsulation, and abstraction.
  • APIs: Arrays, Strings, Collections (List, Set, Map), and Generics.
  • Files & Errors: Exception handling and File I/O streams.
  • Concurrency: Multithreading, thread lifecycle, and synchronization.
  • Modern Java: Lambda expressions, Streams API, and Records.
